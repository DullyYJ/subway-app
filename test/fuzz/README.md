# 경로 무작위 시뮬레이션 (수정 전/후 비교용)
- 실행: `node test/fuzz/route_fuzz.js <index.html> <시나리오 수> <시드> > out.json` (수정 전·후 html 각각), 비교: `node test/fuzz/route_fuzz_analyze.js old.json new.json`
- 경로 유형(도보·지하철·버스·환승 10종)을 섞고, 승차 확정 지연·기지국 선행·위치 채택 지연·역 건너뜀을 변형해 도착 예정·오버레이 현재 역·첫 승차 시각이 진실에서 벗어난 정도를 잰다.
- 주의: '진실'에는 열차 지연(0~3분)이 들어 있어 앱이 미리 알 수 없다 → 절대 오차보다 수정 전/후 차이를 본다.
