				var currentMm = parseInt($('#mm').val());
				var currentYyyy = parseInt($('#yyyy').val());
				var prevMm, prevYyyy;
				if (currentMm == 1) {
					prevMm = 12;
					prevYyyy = currentYyyy - 1;
				} else {
					prevMm = currentMm - 1;
					prevYyyy = currentYyyy;
				}
				$('#yyyy').val(prevYyyy);
				$('#mm').val(prevMm < 10 ? '0' + prevMm : '' + prevMm);
				$('#calendarForm').submit();
			});

			$('.next').click(function(){
				var currentMm = parseInt($('#mm').val());
				var currentYyyy = parseInt($('#yyyy').val());
				var nextMm, nextYyyy;
				if (currentMm == 12) {
					nextMm = 1;
					nextYyyy = currentYyyy + 1;
				} else {
					nextMm = currentMm + 1;
					nextYyyy = currentYyyy;
				}
				$('#yyyy').val(nextYyyy);
				$('#mm').val(nextMm < 10 ? '0' + nextMm : '' + nextMm);
				$('#calendarForm').submit();
			});

				<ul class="ul_list mt-2">
					<li class="fir"><strong>충</strong>외행성과 태양사이에 지구가 위치하여 태양과 외행성의 시황경 차이가 180˚가 되는 현상, 즉 태양-지구-외행성 순서로 위치한 때이다.</li>
					<li><strong>합</strong>지구와 외행성 사이에 태양이 위치하여 태양과 외행성의 시황경이 같게 되는 현상, 즉 외행성-태양-지구 순서로 위치한 때이다.</li>
					<li><strong>내합과 외합</strong>내합과 외합의 시각은 태양과 내행성 (수성, 금성)의 시황경이 같게 되는 시각이며, 내행성이 태양과 지구 사이에 있는 경우를 내합, 내행성과 지구 사이에 태양이 있을 때를 외합이라 한다.</li>
					<li><strong>유</strong>행성의 시적경이 변하지 않는 시간이며, 이 때의 시적위의 변화는 완만하여 항성에 대하여 시운동은 거의 정지된 상태이다.</li>
					<li><strong>최대이각</strong>태양과 내행성의 각거리가 최대로 되는 각도이며, 지구에서 볼 때, 태양의 동쪽으로 최대 각거리에 있는 경우를 동방최대이각, 서쪽에 있는 경우를 서방 최대이각이라 한다.</li>
					<li><strong>근일점</strong>태양과 지구 사이의 거리가 최소가 되는 지점이다. </li>
					<li><strong>원일점</strong>태양과 지구 사이의 거리가 최대가 되는 지점이다. </li>
					<li><strong>월령</strong>바로 직전 합삭 시작으로부터 매일 오후 9시까지의 시간을 말한다.			</li>
					<li><strong>AU (Astronomical Unit)</strong>태양과 지구 사이의 평균거리(1.496 X 10^11km)를 말한다.</li>
					<li><strong>ZHR (Zenithal Hourly Rate)</strong>6.5등성까지는 보이는 맑은 밤, 유성우의 복사점이 천정에 있다고 가정할 때 1시간 동안 한 사람이 맨눈으로 관측할 수 있는 유성의 수, 실제로 관측할 수 있는 것은 이보다 적다.</li>
