# ios-reference — 웹 기준본 (2026-10-20 고정)

iOS 개발용으로 **그대로 보관하는 웹 버전**이다. 안드로이드 앱(`www/`, Capacitor webDir)은 이 날짜 이후 부분마다 웹 코드를 걷어내며 100% 네이티브로 가므로,
iOS 가 따라 만들 때 참고할 **웹 쪽 원본 동작·화면·자료**를 여기에 얼려 둔다.

- `index.html` — 당시 웹 전체(경로·홈·커뮤니티·지도·설정·탑승 추적 PosFusion 포함). 단독으로 열어 동작을 볼 수 있다(서버 주소는 그대로 길동무 서버).
- `metro_native.bin`, `chars3d/`, `privacy.html` — 웹이 쓰는 자료.
- **이 폴더는 앱 빌드(Capacitor `webDir: www`)에 들어가지 않는다.** 고치지 않는다(필요하면 새 기준본을 날짜와 함께 추가).
- 안드로이드 쪽에서 걷어낸 웹 코드의 자리와 이유는 `HANDOFF.md` 의 해당 단계 기록을 본다.
